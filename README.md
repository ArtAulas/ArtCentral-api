# API ArtCentral

## Inspirações:
Observando como artistas em redes sociais dependem da sorte para serem vistos por possíveis clientes, observei uma oportunidade de facilitar esse processo.

## Detalhes do Projeto:
Esse repositório se trata da API para um plataforma que visa conectar artistas e possíveis clientes.  
Através desse projeto, busco aprender novas tecnologias e descobrir novas formas de executar processo que já estou acostumado.  
Também busco concluir esse projeto sem auxílio de IA generativa, seja através de intervenção direta (Claude instalado no VSCode) ou dúvidas pontuais (ChatGPT, Gemini, etc...)

## Tecnologias Utilizadas:
Como linguagem decidi usar o GO, primeiramente por curiosidade e vontade de aprender uma nova linguagem com um projeto real.  

## Principais Aprendizados:
### JWT
Esse projeto foi minha primeira vez implementando JWT do zero, sem auxílio de colegas ou professores.
