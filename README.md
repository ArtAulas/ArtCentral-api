# API ArtCentral

## Inspirações:
Observando como artistas em redes sociais dependem da sorte para serem vistos por possíveis clientes, decidi iniciar um projeto que visa facilitar esse processo.

## Detalhes do Projeto:
Esse repositório se trata da API para um plataforma que visa conectar artistas e possíveis clientes.

## Tecnologias Utilizadas:
Como linguagem decidi usar o GO, primeiramente por curiosidade e vontade de aprender uma nova linguagem com um projeto real.
